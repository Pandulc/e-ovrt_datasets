# Download Scripts

Scripts de descarga para fuentes con URL directa o mecanismo reproducible.

## Construction-PPE

```bash
datasets/scripts/download/download_construction_ppe.sh
```

Este dataset tiene ZIP directo publicado por Ultralytics. Los datasets alojados en Kaggle, Mendeley o Google Drive pueden requerir credenciales, aceptacion manual de terminos o herramientas externas; por eso no se automatizan todavia.
